Eine Sammlung von Community-Projekten, die auf LIZ AI BRASIL basieren.

:::note
Möchten Sie Ihr LIZ AI BRASIL-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-liz](https://github.com/awesome-liz/awesome-liz) und [liz.cafe](https://liz.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
